# Blinkit E-Commerce Data Analysis | SQL & Power BI

## 📌 Project Overview

This project presents an end-to-end analysis of Blinkit e-commerce data using **PostgreSQL and Power BI**. The objective of the project is to analyze business performance across sales, customers, products, deliveries, customer feedback, inventory, and marketing.

The project is divided into two main parts:

* **SQL Analysis** – Data validation, KPI calculations, exploratory analysis, and business insights using PostgreSQL.
* **Power BI Dashboard** – Interactive dashboards for visualizing key business metrics, trends, and performance.
